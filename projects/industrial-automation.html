Industrial Automation System

2024 PLC & Automation Semester Project

Project Overview

This industrial automation project involved the complete analysis, design, and simulation of a PLC-based automated press-fit assembly machine. The system utilizes Sequential Function Chart (SFC) programming, multiple sensor types, and actuator control to achieve precise automated assembly operations.

Key Features

  • Complete machine functional analysis and subsystem identification
  • Sequential Function Chart (SFC) development with step-by-step logic
  • Sensor selection with industrial datasheets and specifications
  • PLC ladder logic programming and simulation
  • Sensor positioning layout and actuator integration
  • Operating mode implementation (Manual/Automatic)

Machine Functional Description

The automated system performs press-fit assembly operations through coordinated subsystems:

  • Feeding System: Component loading and orientation mechanism
  • Processing Station: Press-fit operation with force control
  • Discharge System: Completed assembly ejection and sorting
  • Safety System: Emergency stop, light curtains, and interlock protection

Operating Modes: Manual mode for maintenance and setup, Automatic mode for continuous production cycles.

Sequence of Operation

Initial Conditions

  • All actuators in home position
  • Safety systems engaged
  • No fault conditions present

Start-up Sequence

  1. System power-on and self-diagnostic check
  2. Safety circuit verification
  3. Component feeding system initialization
  4. Operator confirmation and mode selection

Normal Operation Cycle

  1. Part presence detection at feeding station
  2. Component orientation verification
  3. Transfer to press-fit station
  4. Force-controlled press operation
  5. Quality check and verification
  6. Part ejection to discharge conveyor

  • Hydraulic Press: Proportional valve control for precise force application

SFC Structure

  • Step 0: Initial state - System check and safety verification
  • Step 1: Part feeding - Component loading and orientation
  • Step 2: Transfer - Move component to press station
  • Step 3: Press operation - Force-controlled assembly
  • Step 4: Inspection - Quality verification
  • Step 5: Ejection - Completed part removal

PLC Implementation

Ladder Logic Programming

The PLC program was developed using structured ladder logic with clearly commented code sections. Key implementation features include:

  • Modular programming structure with function blocks
  • Emergency stop and safety interlock implementation
  • Fault detection and handling routines
  • Manual/Automatic mode switching logic
  • Production counting and cycle time monitoring
